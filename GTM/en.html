01 · WHY LONELY WORLD

You've read a hundred endings.
None of them were yours.

Before AI, we visited other people's stories. Now stories can finally be yours — but most AI games lose three things along the way.

PAIN — 01

Classic text adventures: the plot is baked in

Any branch tree is finite. On your second playthrough you're not exploring anymore — you're executing a walkthrough.

PAIN — 02

Chatbot role-play: forgotten by morning

Endlessly obliging, endlessly blank. Close the window and nothing remains: no saves, no world, no continuity. Last session's grudge? It never happened.

PAIN — 03

Cloud AI games: the story isn't yours

Your character lives on someone else's server — subject to price hikes and shutdowns, with a translation layer between you and every line.

Lonely World puts an infinite-plot AI inside an engine that remembers —
the world is co-created with you, memory stays with you, and the story lives on your own disk.

03 · CORE VALUE

An engine that remembers is what makes infinite plot worth it

Every feature answers one question: how do you make an AI-generated story worth investing three months in?

NO-SCRIPT

Unscripted plot

No quest log, no critical path. The story happens because you opened the door — the AI improvises from whatever you do, however absurd.

CO-CREATE

Co-created worlds

Five questions at the start: era, place, people, society. The stage is built from your imagination, not rolled from a random table.

MEMORY

Persistent memory

Items, skills, personality, grudges — all persisted to disk. Token-aware context plus automatic memory compression: long campaigns don't "forget".

STORY.MD

Literary ghostwriter

Opt in, and every turn is also rewritten as literary prose into story.md. You play the game; a novel writes itself alongside.

BYO-MODEL

Any model

OpenAI, Anthropic Claude, Ollama / vLLM — anything OpenAI-compatible. One flag to switch providers. No lock-in, ever.

CLI + WEB

Two ways in

The terminal for ritual, the browser for comfort — a multi-user Web UI with streaming replies, Markdown rendering, and independent per-user saves.

07 · FAQ

Before you press Enter

Q1What does it cost?＋
The game is MIT-licensed and free. You pay only for the model API you point it at — typically pennies per session. With a local Ollama / vLLM model it costs nothing at all.
Q2Do I need to use a terminal?＋
No. Install the web extra (pip install "lonely-world[web]") and run lonely-world-web, then open localhost:7860 — create or pick a character entirely in the browser.
Q3Which models does it support?＋
Any OpenAI-compatible API: OpenAI, Anthropic Claude, and local models via Ollama or vLLM. Switch with --provider or environment variables — models change, saves don't.
Q4Where does my data live?＋
Entirely in the local/ directory on your machine; nothing touches a third-party server except the model API you configure. API keys go to the system keychain, and stories export to Markdown.
Q5Will it "forget" things in long campaigns?＋
That's the core engineering: token-aware context trimming plus automatic memory compression. Key facts and grudges get archived and kept, not truncated away.
Q6The AI took the story somewhere I hate. Now what?＋
Type undo. The last turn is rolled back and the world behaves as if it never happened. You hold final cut on your story.
